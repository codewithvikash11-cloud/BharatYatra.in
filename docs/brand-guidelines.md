# BharatYatra brand

## Identity

The BharatYatra mark pairs a rising sun with nested travel arches: a simple cue for discovery and welcome, drawn as original project artwork. Use the compact SVG on light and dark backgrounds; it has transparent space outside the circular mark. Keep clear space around it equal to the sun-dot diameter and do not stretch or recolor the paths.

## Palette

| Token | Color | Use |
| --- | --- | --- |
| Forest | `#173D36` | Primary brand, navigation, strong buttons |
| Deep teal | `#285D57` | Links and interactive focus |
| Warm paper | `#F5F3EC` | Main page background |
| Soft ivory | `#FFFDF8` | Cards and readable surfaces |
| Terracotta | `#CE6B35` | Editorial accents |
| Sun gold | `#E6A064` | Small mark details and emphasis |
| Muted slate | `#647775` | Supporting text |

Check text/background contrast when changing tokens. Do not use accent colors alone to convey status.

## Type and imagery

Use readable serif display type for travel/editorial headings and sans-serif UI/body text. Hindi content uses system Devanagari-capable fallbacks. Keep body line lengths comfortable and preserve visible keyboard focus. No licensed photography or existing photo assets were present during this audit. Do not add decorative stock imagery that could be mistaken for a real destination; use verified `media_assets` content after the owner configures storage and content.

## Usage

The public site and admin studio share the same mark, forest/terracotta palette, and serif/sans pairing. Admin screens may use tighter spacing and denser controls. Keep the user interface calm, legible, and useful before adding ornamental effects.
